# salmi.me

The source for [salmi.me](https://salmi.me), built with Astro, TypeScript, MDX, and Astro content collections.

## Development

```sh
npm install
npm run dev
```

Create production files with:

```sh
npm run build
```

## Content

- Writing lives in `src/content/writing/`.
- The web resume lives in `src/pages/resume.md`.

Collection schemas are defined in `src/content.config.ts`.
